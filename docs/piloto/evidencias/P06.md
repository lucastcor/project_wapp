## Riscos residuais (baixos, aceitos para o piloto)

- Alerta de dead letter não tem janela de tempo: depois do primeiro envio com falha, fica ativo até alguém tratar.
- Remover o usuário dono deixa a posse humana sem dono (`ON DELETE SET NULL`); só a devolução forçada por admin libera.
- Mensagens recebidas durante a posse não são retomadas pelo bot na devolução (decisão de produto registrada em CONTRATOS).
- Pendência duplicada possível apenas com processamento concorrente do mesmo contato fora do worker (simulador).
- Lease só é renovada antes de efeitos: geração muito lenta (> 300 s) manda o job para revisão sem efeito real.
- Aviso ao cliente ao assumir/devolver fica a critério do operador (sem mensagem automática).
