## Compatibilidade / rollback

- Versões antigas com política inválida: leitura cai no default documentado (não derruba atendimento); publicação exige validação.
- Empresas só com contexto legado seguem atendendo (`legacy_context`) até a próxima escrita, que publica versão.
- Mudança de comportamento intencional (D13): handoff agora avisa o cliente por padrão; intenção fora de `auto_reply_allowed_for` gera pendência.
- Migration 069 é aditiva. Rollback de código mantém a tabela sem uso.

## Riscos / pendências

- `inbound_repository.now_iso()` com largura variável comparada como texto (registrado para P06).
- Valores de preset são materializados na versão ao salvar; trocar `business_type` depois não reaplica preset (documentar em P07).
- Handoff para intenção obrigatória depende de pendência; UI de fila/posse humana é P06/P07.
